\# 火箭开仓+自稳算法工程

> 项目来源：\*\*2026中国大学生飞行器设计创新大赛\*\*



\## 项目简介

本工程为竞赛火箭机载控制代码，基于STM32开发，实现火箭开仓控制、姿态自稳等核心功能。

代码会持续迭代优化，除本次大赛任务外，后续将移植拓展至更多飞行器项目，不断新增功能、优化算法。



\## 工程信息

\- 开发环境：Keil5 MDK-ARM (uVision5)

\- 主控芯片：STM32F10x

\- 主要模块：MPU6050姿态采集、姿态解算、PID自稳控制、开仓执行机构驱动



\## 使用说明

1\. 使用Keil5打开工程文件 `Rocket\_Stable\_v3.uvprojx`

2\. 编译前确认硬件连线与参数配置

3\. 切换Git历史版本前，请\*\*关闭Keil\*\*，避免文件占用冲突
